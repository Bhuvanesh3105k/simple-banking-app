Simple Banking App

Project Description

This is a simple banking application developed using Python and Streamlit. It allows users to add money, check their current balance, and send money.

Features

- Add Amount
- Check Balance
- Send Amount
- Insufficient Balance Validation
- Positive Amount Validation

Technologies Used

- Python
- Streamlit

Concepts Used

- Object-Oriented Programming (OOP)
- Classes and Objects
- Conditional Statements
- Functions
- Session State

How to Run

1. Install Streamlit:
   
   pip install streamlit

2. Run the application:
   
   streamlit run app.py

Project Note

This is a basic banking demo application developed for learning purposes. It does not perform real banking transactions or use permanent database storage.
